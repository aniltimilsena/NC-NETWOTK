# NC-Network

NC-Network is a casting and professional talent platform (frontend + Express server + Firebase Functions) used by the NepalCasts workspace.

Quick start

1. Install dependencies (frontend):

```bash
cd NepalCasts
npm install
```

2. Run frontend dev server:

```bash
npm run dev
```

3. Run backend dev server (separate terminal):

```bash
npm run dev:server
```

Testing & linting

```bash
# run tests
npm test

# run linter
npm run lint
```

Where to look

- Frontend: `NepalCasts/`
- Server (Express): `NepalCasts/server/`
- Firebase Functions: `NepalCasts/functions/`
- Firestore rules: `NepalCasts/firestore.rules`

Maintainers

- Project brain and architecture notes: `NepalCasts/brain.md`
- For deployments: see `NepalCasts/firebase.json` and `NepalCasts/vercel.json`
